# Modern Missile Mod

**《皇牌空战 8：希芙之翼》导弹体系重制**

版本 1.0.0 · 单人 / 离线 · UE4SS Lua

---

## 概述

导弹是《皇牌空战》系列的招牌武器，但它的运动学包线一直远低于现代战斗机飞行员所熟悉的水平。
锁定距离短、导引头视场窄、转向速率低，导弹更像一支近距离烟花而不是制导武器。这一点在 HOTAS
座舱模式下尤其明显——刚接触 HOTAS 的玩家几乎无法体会到超视距交战的乐趣。

本 Mod 以现代空战实践为参照，重建玩家全部导弹的性能包线：更远的截获距离、符合现代格斗弹的
导引头框架角、比例导引前置量、更高的转向速率、真正有意义的战斗部，以及足以支撑一场高强度
出击的备弹基数。

本 Mod 优先为 HOTAS 座舱飞行设计，但键盘与手柄同样可用——只是数值会比原版平衡更“慷慨”。

## 设计取向

现实中的超视距（BVR）交战距离，相对于《皇牌空战》任务的战场尺度而言过于夸张。本 Mod 没有
直接照搬现实数据，而是给出一套**压缩后的 BVR 包线**：既足以打出 F-pole 交战，又不至于让导弹
飞出战场、让玩家无事可做。

由此形成三层射程结构：

- **近距格斗**：格斗弹截获更早，可大离轴角跟踪，单次急转难以摆脱。
- **中距拦射**：中距弹奖励高度、速度与目标分配，飞行寿命经过延长，锁定距离真实可达。
- **防区外打击**：巡航弹与反舰弹可在防区外发射，代价是较长的飞行时间。

## 改动内容

| 系统 | 改动 |
| --- | --- |
| 截获 | 各弹种的锁定距离（`LockonRange`）与锁定圆锥角（`LockonAngle`） |
| 导引头 | 框架角（`MaxHomingAngle`）、跟踪转向速率（`MaxRotationAngle`）、比例导引前置量（`HomingForesightAmount`） |
| 运动学 | 两个速度强化弹种（LASM、LAGM）的最大速度与加速度 |
| 续航 | 按新锁定距离自动延长飞行寿命 |
| 杀伤 | 各弹种战斗部伤害与爆炸半径 |
| 后勤 | 按机型、按改装等级的备弹基数 |

改动范围仅限**玩家武器**。敌方导弹使用独立的数据表，保持原样，威胁态势不变。

## 前置要求

- **《皇牌空战 8：希芙之翼》**（Steam 版），单人 / 离线
- **UE4SS 3.0.1**（或更新构建），安装于 `Game\Binaries\Win64\`
- **无 EAC 离线启动器**（任意同类工具）——本 Mod 为纯 Lua 脚本，不修改可执行文件，但必须在
  关闭 EasyAntiCheat 的前提下运行
- 不得同时启用其他修改同一批武器默认对象或机型参数表的 Mod

HOTAS **不是**必需项，键盘与手柄均可正常使用。

## 安装方法

1. 确认 `ACE COMBAT 8\Game\Binaries\Win64\` 已安装 UE4SS（`ue4ss\UE4SS.dll` 及其代理 DLL）。
2. 将 `ModernMissileMod` 文件夹复制到 `ACE COMBAT 8\Game\Binaries\Win64\ue4ss\Mods\`。
3. 以离线 / 无 EAC 模式启动游戏，进入任务。

卸载只需删除文件夹——不写入存档，不修改游戏文件。

## 注意事项

- **每局切换一次武器。** HUD 锁定圈在武器被选中时读取截获距离；进入任务后切一次武器即可刷新。
- **每局重新写入。** 游戏会为每次出击重建武器类；本 Mod 在关卡载入后的前几秒内完成改写，随后
  完全空闲——不轮询、不逐帧执行。
- **按地图生效。** 主菜单、机库、简报、过渡地图一律跳过，仅处理 `Maps/Ingame/...`。
- **敌方武器不变。** 威胁水平与原版一致。
- **数值定位。** 表中数值是本 Mod 的平衡选择，并非对现实性能的精确复刻。

## 兼容性

- 仅限单人模式。
- 不兼容其他改写同一批武器默认对象或机型参数表的 Mod（其他导弹重平衡、备弹倍率类）。请择一使用。
- 可与座舱 / HOTAS、视角、音效、涂装类 Mod 共存。
